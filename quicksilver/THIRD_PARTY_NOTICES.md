(no CDN, no web fonts, hand-drawn icons, system font stack).

## Obfuscators whose output is part of the test corpus and sample files

`tests/corpus/obfuscated/**` and `data/samples/**` contain scripts that were **generated by running** the tools below on programs written for this project
(`tests/corpus/originals`). They are outputs, not copies of the tools' sources, but obfuscator output contains code emitted by the tool's templates, so the notices are kept with them.
The recovery modules were written after reading each tool's source and output; no source file of these tools is copied into QuickSilver.
