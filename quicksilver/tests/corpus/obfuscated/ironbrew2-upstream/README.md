# IronBrew 2: the sample output the project itself ships

`out.lua` is the file IronBrew 2 2.7.0 produced from `test.lua` and left in its repository
(`IronBrew2 CLI/bin/Debug/netcoreapp3.1/out.lua`, https://github.com/Trollicus/ironbrew-2, MIT licence, Copyright (c) 2019 DefCon42;
the licence text is in `THIRD_PARTY_NOTICES.md`). It is kept unchanged. Unlike the fixtures in `../ironbrew2`, which were
generated for this project, it was made by the tool's author on their own machine, so it also shows that the format
QuickSilver reads is the one the released tool writes.
