Gate Resolver

Passive redirect-chain inspector for authorized URLs.

Follows only standard HTTP 3xx redirects and reports the chain, final URL, and status codes. It detects and clearly flags — but never bypasses — any step needing a human (CAPTCHA, anti-bot challenge, login, paywall, ad-gate, or JavaScript/meta redirect), and stops there. No JS is executed; no CAPTCHA, auth, or access control is circumvented.

    Use only on URLs you are authorized to inspect.
